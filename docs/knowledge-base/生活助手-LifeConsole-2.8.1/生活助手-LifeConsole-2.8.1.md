# PRD：Life Console 2.8.1

状态：PO 于 2026-08-31 明确修复语义并要求实施。

## 1. 问题

工作台 Todo 的“今日”Tab 会隐藏计划开始时间晚于当前时刻、但仍落在今日的未完成 Todo；只有当时间超过计划开始时间后才会展示。

## 2. 目标语义

- 未完成 Todo：`planned_start_at` 落在当地今日自然日 `[00:00, 次日 00:00)` 即在“今日”展示，不与当前时刻比较。
- 已完成 Todo：保留既有规则，`completed_at` 落在当地今日时可被状态筛选回捞。
- “全部”Tab、状态筛选、排序、甘特、写入、软删除与数据模型不变。

## 3. 成功标准

1. 当前时刻早于今日 Todo 的计划开始时间时，该 Todo 仍在“今日”列表与甘特中展示。
2. 昨日或明日计划开始的未完成 Todo 不混入“今日”。
3. 今日完成项的既有回捞语义不回归。

## 4. 非目标与门禁

- 不修改 Supabase Schema、RPC、RLS、Owner 数据或时区配置。
- 不引入定时刷新或客户端隐藏逻辑。
- 本轮修复不授权 Preview、合并或 Production 发布。
