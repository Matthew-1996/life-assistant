# 设计方案：Life Console 2.5.0

状态：Gate 2 v2 已由 PO 于 2026-08-20 确认，可按本方案进入实现。

评审资产：[Life Console 2.5.0 正式视觉评审稿](视觉评审稿-生活助手-LifeConsole-2.5.0.html)。

## 1. 设计原则

- 延续 `apple-top-level-design-system`：大留白、明确层级、圆角材质、低噪声色彩和克制动效。
- 首屏先回答“本周关注什么、今天做什么、外部发生什么”，再提供记录入口。
- 颜色不作为唯一状态信号；优先级、Todo 状态、逾期和趋势均同时使用文字或图标。
- 桌面内容宽度为 `min(1280px, calc(100vw - 64px))`；任何页面和卡片都不得越出可用视口。移动端 390px 单列，无横向页面滚动。
- 支持 `prefers-reduced-motion`、键盘操作和可见焦点；正文最低 14px，主要文本对比度达到 WCAG AA。

## 2. 全局框架

- 顶部：Life Console 标识、四页导航、Owner 会话入口。删除真相源宣传横幅。
- 宽桌面：顶部导航固定但不遮挡内容；页面左右边距 32px，区块间距 24px。
- 中等桌面：内容区不足 1180px 时，Todo/新闻、记录主栏/复盘、两张趋势卡均改为上下布局；不通过压缩字号、截断内容或页面横向滚动维持双栏。
- 视觉评审页中的固定 1440px 画板仅用于标注目标尺寸；画板按浏览器可用宽度等比缩放，缩放不代表产品页面产生横向滚动。
- 移动：导航变为底部四项 Tab；页面边距 16px，所有双列/多列降为单列或卡片横向内部滚动。
- 弹窗：居中模态层，背景轻度模糊；危险操作按钮使用系统红，默认焦点停留在取消。

## 3. 工作台

### 寄语横幅

- 全宽 hero，高度桌面 240px、移动 210px。
- 左下展示“本周寄语”、正文、更新时间；右下展示摄影师和 Unsplash 归因。
- 图片加载失败或无 Key 时使用蓝紫渐变，不显示破损图片或空归因。

### Todo 与甘特

- 内容区达到 1180px 时 Todo 占 8/12 栏、新闻占 4/12 栏；不足时新闻完整移到 Todo 下方。Todo 区顶部提供“今日/全部”分段控件和快速新建。
- 列表行展示序号、标题、P0/P1/P2、状态、DDL；逾期用“已逾期”文字和系统红点。
- 编辑使用侧边 Sheet；状态切换提供明确按钮，不用拖拽作为唯一操作。
- 行尾提供红色“删除”文字按钮；点击后弹出二次确认，明确说明只从活动列表与甘特移除、不会永久清除。删除成功后原行立即消失；2.5.0 不展示 Todo 恢复入口。
- 甘特在列表下方，以 14 天为默认窗口；计划条、当前时间线、实际完成标记和逾期尾部可区分。

### 新闻与今日锚点

- 新闻卡展示分类、国内/国际、标题、160 字内摘要、来源和发布时间；不内嵌全文。
- 降级版本顶部显示“上一份成功摘要”和更新时间；无缓存显示重试空态。
- 今日锚点在工作台底部全宽呈现，原样复用 2.4.0 的 `起床`、`身体 / 光照`、`生活动作`、`晚间降速` 四项，不改为 Todo 或新的行动模型。
- 每项同时显示说明与 `未填写 / 完成 / 最低版 / 跳过` 四种语义；当前状态有文字和选中样式，点击其他可写状态即可修改并显示保存反馈。
- 区块顶部显示“已填写项 / 4”的进展；该计数只统计非空状态，不把未填写推断为跳过。
- 宽桌面使用 2×2 卡片；单卡的文字与四段状态控件放不下时，先在卡内上下排列；内容区不足 1180px 时四张卡整体改为单列。移动端始终单列。

## 4. 记录页

- 页面头部为单栏标题区，删除“写入语义 / 草稿不会自动生效”卡片。
- 对话式记录位于首区，保持文本输入和保存状态，不显示重复的原文预览或兜底表单。其下依次为日记记录与复盘。
- 日记卡默认态仅显示标题、日期、用户原话和“展开整理”；操作菜单含编辑、删除。
- 编辑沿用原“线上记录与修订”表单，包含日期、标题、原文和标签；不另建简化表单。
- 删除弹窗明确说明“可在已删除中恢复”，按钮为“取消 / 移到已删除”。
- 已删除列表使用弱化卡片与恢复按钮；恢复冲突显示“记录已变化，请刷新后重试”。
- 复盘使用中文字段栅格；未知结构按纯文本展示；卡片正文最多 320px，内部滚动。
- 纯合成 Preview 复用同一套日记卡、编辑、删除确认和恢复界面；顶部明示“只在当前页面生效，刷新后重置”，不伪装成真实保存。

## 5. 进展页

- 顶部目标卡保持简洁，不混入自然周说明。
- 趋势区按主观信号、活动、睡眠三组展示折线或柱形图，并在图下显示确定性观察。
- 最近 7 天使用实色，前 7 天使用浅色；少于 3 个样本时用“数据不足”空态替代误导性趋势。
- 睡眠时刻使用 7 行表格：日期、入睡、醒来、离床；移动端保持表头并允许卡片内部水平滚动，页面本身不滚动。

## 6. 状态与反馈

| 状态 | 设计 |
|---|---|
| 加载 | 区块级骨架屏；保留页面结构 |
| 空数据 | 说明缺少什么及唯一下一步，不生成示例个人数据 |
| 保存中 | 禁用重复提交并显示进行中 |
| revision 冲突 | 保留用户输入，提示刷新最新数据后重试 |
| 新闻陈旧 | 显示上次成功时间，不伪装为今日结果 |
| 外部图片失败 | 内置渐变，隐藏无效归因 |
| 删除/恢复 | 二次确认、成功 Toast、列表即时更新 |

## 7. 正式视觉评审清单

Visual Companion 需同时展示：

1. 1440px 工作台、记录、进展和 Todo 甘特；在较窄浏览器中整张画板仍完整位于屏幕内。
2. 390px 工作台、记录、进展。
3. 日记删除确认、已删除与恢复状态。
4. 今日锚点四项、四种语义、填写进展和修改入口。
5. 新闻陈旧/无缓存、趋势数据不足和寄语渐变降级。

PO 已确认上述稿件与本方案；实现仍须保持屏内布局、2.4.0 今日锚点语义及其余独立发布门禁。
