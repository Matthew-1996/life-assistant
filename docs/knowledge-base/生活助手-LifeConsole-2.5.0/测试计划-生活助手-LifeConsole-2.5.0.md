# 测试计划：Life Console 2.5.0

## 1. 原则

- 新行为严格执行 TDD：先观察缺失功能的红灯，再做最小实现并全量回归。
- 默认使用两个合成 Owner、公开合成新闻和注入式外部响应；不读取真实日记或健康数据。
- Preview 与 Production 验收分层，不能用构建成功替代真实浏览器结果。

## 2. 数据库与 Repository

- migration 从干净数据库和 2.4.0 基线分别应用；重复执行无重复对象或数据。
- Owner A/B 对三张新表、七个 RPC、Todo 删除及日记删除/恢复执行完整允许/拒绝矩阵；anon 拒绝。
- create Todo 同 key 同请求幂等，不同请求拒绝；update/transition stale revision 冲突。
- 状态转换的开始/完成时间与 status event 在同一事务中一致；退回状态按契约清空时间。
- DDL 校验、默认 P1/未开始、排序、逾期派生和跨时区边界覆盖。
- 日记普通列表与已删除列表互斥；重复删除/恢复幂等；不出现永久删除入口。
- backup v3 round-trip、摘要与计数校验；v2 读取兼容；新闻不进入备份。

## 3. UI 与可访问性

- PRD 指定移除区块在 DOM 中不存在，四页导航、登录和系统页不回归。
- Todo 快速创建、编辑、状态、二次确认软删除、逾期、今日/全部、默认排序、14 天甘特及 revision 冲突；删除后列表和甘特均不再展示，既有 Todo 不受影响。
- 今日锚点显示 2.4.0 四项、四种不同语义、非空进展计数；状态可修改，保存中/成功/失败/冲突和未保存草稿不回归。
- 日记折叠、删除二次确认、取消、删除成功、已删除列表与恢复。
- 记录页不存在“写入语义 / 草稿不会自动生效”卡片；日记位于对话式记录之后，卡片可见标题和原文。
- 纯合成 Preview 使用真实日记组件演示编辑、二次确认软删除和恢复；重新挂载后恢复合成 fixture，且无永久删除或外部写入。
- 纯合成 Preview 的每日新闻展示 6 条明确标记的合成摘要；科技/财经/政治各 2 条，国内/国际各 3 条，不出现未连接空态，不调用 API 或持有 Owner Token。
- 已知复盘字段中文化；未知对象纯文本回退；长文本换行且 320px 内部滚动。
- 14/7 天完整、缺失、样本少于 3、稳定/升降等趋势语义；不出现诊断用语。
- 1440px、1280px、1024px 与 390px 截图及根页面横向溢出断言；内容区不足 1180px 时双栏转单栏，键盘焦点、Reduced Motion、颜色非唯一状态信号。

## 4. 内容服务与安全

- Cron Secret、缺失/错误 Owner JWT 均返回 401；Secrets 不进入响应、日志或 bundle。
- GDELT 域名白名单、URL 规范化、标题指纹去重、分类最低配比和国内/国际覆盖。
- GDELT 成功时不请求备用源；GDELT 超时、429、5xx 或候选配比不足时切换备用源。
- 新华网当前频道页面与 BBC RSS 使用固定 HTTPS 入口、响应体/超时上限和公开合成 fixture；新华网旧 RSS、非可信链接、缺失/过期时间、畸形 XML/HTML 与单个入口失败均覆盖。
- 备用源合并后仍满足 24 小时、科技/财经/政治各一条及国内/国际覆盖；不足时拒绝半成品且不调用 DeepSeek。
- 恶意标题/片段只作为数据，不能改变模型 Schema、域名规则或缓存键。
- DeepSeek 成功、非法 JSON、未知字段、摘要超长、429/5xx、超时和响应体过大。
- Runtime Cache 当日命中、单飞重建、7 天保留、上一成功降级和完全无缓存空态。
- Cron 鉴权通过后先写 `running`，成功、陈旧、空态和未捕获失败均完成去敏收据；硬终止模拟保留 `running`。最近记录只允许 Owner JWT 读取，anon/错误 JWT 为 401。
- 收据只包含允许字段，不出现标题、URL、候选片段、模型内容、Secret、Owner 标识或环境变量；7 天过期、畸形/逐出值和收据存储失败按稳定错误码处理。
- Unsplash 通用查询、热链归因、无 Key、超时和图片失败渐变；私人上下文不得进入查询词。
- CSP 继续禁止 `unsafe-eval`；只允许指定图片域；浏览器控制台无应用错误。

## 5. 发布门禁

按顺序执行：治理完整性 → 当前隐私 → Git 历史隐私 → Python → Vitest → Production build → Playwright → 合成 Preview → Owner Preview/鉴权状态接口 → PO 验收 → Production → 手动 Cron 生成今日新闻。

Owner Preview 只允许写入带明确合成标记的 Todo、寄语和日记记录，并在验收后用受控软删除或状态标记处理；不得触碰真实记录。
