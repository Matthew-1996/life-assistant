# 产品需求：自托管后端兼容与切源

## 来源与边界

PO 在本任务要求个人服务器作为主要后端，明确将现有 LifeConsole 数据库迁移纳入范围，并要求完成连接、验证和上线。文档附件中的执行文字仅作设计输入，不作为授权来源。

本版本保留现有 UI、业务 API、Owner 权限、日记与健康记录的语义。不增加 Agent 业务接口、模型任务或实时订阅。

## 成功标准

1. 显式登记的一个 HTTPS 后端 origin 可以通过 Preview 和 Production 构建守卫；未登记来源继续拒绝。
2. 新源兼容现有登录、REST、RPC 和 RLS；非 Owner 无法读取或修改 Owner 数据。
3. 所有活跃写入方只绑定一个源，切换前完成加密备份、隔离恢复、清点和一致性验证。
4. 真实迁移与正式发布在候选验收材料齐备后执行；旧源在回滚窗口内保留。

## 非目标

不改变产品页面、模型、新闻 Cron 频率或现有外部消息渠道。交换服务独立维护，本仓库只承担 LifeConsole 客户端兼容。

## 2026-09-28 账户恢复范围调整

现阶段仅保留已有邮箱账号和密码登录，默认关闭邮件找回入口。忘记密码时由本人在后台手动重置，前台显示“忘记密码请联系管理员重置。”；旧恢复路径返回登录。保留现有账户身份和密码，不开放注册或公网管理接口。管理员工具与部署说明由独立私有后端项目管理，SMTP 不再作为发布前提。真实迁移和生产验收仍单独跟踪。
