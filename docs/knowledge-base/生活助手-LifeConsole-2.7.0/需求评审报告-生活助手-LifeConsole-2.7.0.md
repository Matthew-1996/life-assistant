# 需求评审报告：Life Console 2.7.0

状态：Gate 1 已由 PO 于 2026-08-29 确认。

## 1. 结论

需求成立。它会改变 Todo 的默认展示和验收标准，因此不作为无版本快速修改，以 2.7.0 建立完整知识库。

## 2. 已确认决策

| 议题 | 决策 |
|---|---|
| 作用范围 | 同时作用于“今日”和“全部” |
| 控件 | 项目状态多选 |
| 默认值 | 未开始 + 进行中 |
| 已完成 | 默认隐藏，可主动回捞 |
| 展示面 | 列表、序号、甘特图同源 |
| 持久化 | 本版本不做 |

## 3. 方案比较

| 方案 | 优点 | 局限 | 结论 |
|---|---|---|---|
| 直接永久隐藏已完成 | 最简单 | 无法回捞异常状态或历史项目 | 拒绝 |
| 只过滤甘特图 | 改动小 | 列表和甘特图信息不一致 | 拒绝 |
| 共用多选筛选 | 默认降噪且可回捞，两个展示面一致 | 增加一组本地 UI 状态 | 已选择 |

## 4. 评审结论

Gate 1 通过；可按共用投影方案进入设计与技术实现。本结论不授权 Preview、合并或上线。
