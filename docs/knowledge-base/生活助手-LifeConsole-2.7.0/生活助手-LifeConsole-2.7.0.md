# PRD：Life Console 2.7.0

状态：Gate 1 已由 PO 于 2026-08-29 确认。

## 1. 背景与目标

Todo 的“全部”和“今日”范围会同时把已完成项目给到列表和甘特图，随历史数据增长会稀释当前行动信息。目标是默认聚焦未开始与进行中项目，同时保留主动回捞已完成项目的能力。

## 2. 范围

- 在 Todo 面板增加“项目状态”多选筛选，选项为未开始、进行中、已完成。
- 首次打开默认选中未开始和进行中，默认不展示已完成。
- “今日”与“全部”共用当前筛选选择，切换 Tab 不重置。
- Todo 列表、显示序号和 14 天甘特图使用同一筛选后集合。
- 用户可选中“已完成”回捞项目；也可取消所有状态并看到明确空状态。
- 项目在当前页面被更新为已完成后，如已完成未入选，立即从列表和甘特图消失。

## 3. 非目标

- 不修改 Supabase Schema、Repository Port、RPC、RLS、排序或删除语义。
- 不持久化筛选偏好，不写入 Owner 数据或浏览器存储。
- 不改变“今日”的日期范围和“全部”的读取范围。
- 不在本版本处理 2.6.0 的 iPhone 发布后复验。

## 4. 成功标准

1. 两个 Tab 默认都不显示已完成 Todo。
2. 选中已完成后，对应项目同时出现于列表和甘特图。
3. 状态流转后页面立即按筛选重新投影。
4. 全部取消选中时，列表与甘特图的空状态与“数据源无项目”区分。
5. 390px 视口的筛选项不越界、不重叠，其他 Todo 操作无回归。

## 5. 门禁
