# 设计方案：Life Console 2.7.0

状态：Gate 2 已由 PO 于 2026-08-29 确认。

## 1. 信息架构

“项目状态”筛选位于 Todo 标题 / 范围 Tab 与新建表单之间。它控制当前 Todo 范围的列表和 14 天甘特图，不控制新建表单。

## 2. 交互

- 默认只展示一个紧凑的“项目状态”触发器，并在触发器内摘要当前选择；点击后以浮层展示三个可独立开关的复选项：未开始、进行中、已完成。
- 默认选中前两项；选中态用复选框和浅蓝背景同时表达，不只依赖颜色。
- 复选框本体为紧凑的 14×14px；每个选项仍保留约 38px 的整行点击区域，视觉尺寸与触控目标分离。
- 浮层覆盖在原有表单和内容上方，打开或多选时不改变下方内容的位置；连续勾选不会自动关闭。
- 再次点击触发器、点击浮层外部或按 `Escape` 关闭；`Escape` 关闭后焦点回到触发器。
- 切换“今日 / 全部”保留筛选状态。
- 取消所有状态是合法操作，不自动重置。
- 列表空状态为“当前状态筛选下没有 Todo。”；甘特图为“当前状态筛选下没有可展示的计划。”

## 3. 响应式与可访问性

- 触发器暴露展开状态并关联浮层；状态组使用可读的 `role="group"` 和标签，每个选项使用原生 checkbox。
- 浮层限制在 Todo 面板宽度内；选项允许换行，390px 下不溢出、不相互重叠。
- 保留现有“今日 / 全部”控件、Todo 行、操作按钮与甘特图水平滚动设计。

## 4. 设计验收

- 首屏从紧凑摘要中能直接看出默认已选的两个状态。
- 选中已完成后，列表和甘特图同时回捞。
- 展开浮层前后，新建表单和列表的纵向位置不变。
- 筛选不改变 Todo 原始状态，也不表现为删除。
