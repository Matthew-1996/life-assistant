## 产品与设计

预约编辑新增「时间类型」：定时（默认）/ 全天。全天隐藏时钟字段，月历和详情显示「全天」。现有预约默认定时。有限周重复由认证调用方生成独立预约，不新增无限重复引擎、不发送提醒。

## 技术与验证

新增 time_kind 白名单字段（timed/all_day）。全天保存上海当地零点至次日零点的半开区间；定时保留同一天且结束晚于开始规则。RPC 增加默认 timed 参数，保留 Owner 校验、幂等键、版本冲突和软删除；timed 指纹维持兼容，全天指纹区分类型。备份按完整行导出，验证新增字段通过 ZIP 与隔离库恢复。

验证范围：表单隐藏时间、全天显示及编辑、定时回归、数据库时间边界/权限/幂等/冲突、备份恢复、生产构建、窄屏及桌面浏览器、生产数据读回。
