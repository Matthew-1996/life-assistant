# 技术方案

迁移 20260929052021_fitness_all_day 增加 time_kind，允许 timed/all_day，默认 timed。全天为上海当地零点到次日零点的半开区间；定时仍要求同一天、结束晚于开始。

create/update RPC 追加默认参数，替换旧签名以避免 PostgREST 重载歧义；timed 幂等指纹保持旧版本兼容，all_day 指纹包含类型。Owner 隔离、权限、版本冲突和软删除保持原约束。

部署顺序：备份并隔离恢复验证，数据库事务迁移并比较原记录，发布前端，认证 API 有限录入，完整读回，追加加密备份。原记录比较排除唯一新增字段 time_kind，其他字段必须一致。

回退：前端可切回旧部署，但应保留数据库字段与已录入全天数据；不能以迁移前备份直接覆盖后续写入。业务 ZIP 旧版缺字段，未来导入必须归一化 timed；现有恢复走原 schema 整库恢复再迁移。
