## 真相源边界

- Git：通用职业指导规则、空白模板和去敏方案；不建设 App 或数据服务。
- iCloud 原文真相源：`career/个人知识库/`，保存原生导出、可读副本、图片、附件、来源树、版本和完整性记录。
- iCloud 派生层：`career/02-职业证据/` 至 `career/06-简历与求职/`；只引用来源编号，不复制为第二份原文真相源。
- 兼容入口：`career/01-原始资料/` 不再接收原文，只保留迁移说明或指向新原文库的指引。
- 提醒：只传递任务说明和输入输出清单，不携带原文、敏感摘录或服务标识。

## 真实材料迁移

1. 先按用户清单建立一级类目，再递归保存知识库子节点。
2. 每个节点尽量同时保存平台可提供的原生导出、离线可读正文、图片、附件和恢复元数据。
3. 任何权限失败、截断、附件缺失或格式不支持都标为“部分”或“失败”，不得宣称完整。
4. 原文和迁移清单只留在 `career/个人知识库/`；Git 仅记录去敏设计、使用和验收规则。
