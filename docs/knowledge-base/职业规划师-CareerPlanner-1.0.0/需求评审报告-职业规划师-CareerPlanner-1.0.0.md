## 2. 关键决策

- D1：采用生活助手内的专业 Career Planner，不建立第二个生活系统或 App。
- D2：原始材料优先完整保存；脱敏副本由用户在具体输出场景另行决定。
- D3：原始层不可变，证据层、分析层和交付层分别维护。
- D4：首周职业整理是唯一执行主项；周末完全自由。
- D5：提醒只在工作日 14:30 触达一次，包含完整议程但不包含敏感原文。
- D6：职业路径分析最多同时维护一主两辅，纳入可持续工作约束。
- D7：真实材料逐份授权导入；方案确认不等同于数据授权。

## 3. 风险与控制

| 风险 | 控制 |
|---|---|
| 公司资料的权限或保密义务不清 | 先保存用户明确授权且有权处理的内容；标记来源与权限状态 |
| 链接或长文被截断 | 完整性字段、字节数和哈希校验；失败不生成“完整”结论 |
| 简历夸大或指标幻觉 | 证据卡追溯；事实/推断/未知三分法；数字需用户确认 |
| 职业任务挤占恢复时间 | 21:30 停止、30 分钟降级、周末不补做 |
| 提醒泄露敏感信息 | 仅任务元信息，不含原文、链接、项目名或具体业务数据 |
| 多份文档重复维护 | 原始层唯一、证据层引用来源、交付层由证据派生 |
