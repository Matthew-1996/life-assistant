## 2. 验收清单

### 本地知识库

- `career/` 目录名称和排序清楚，用户可直接浏览。
- 原文件或完整原文保留；新版本不会覆盖旧版本。
- 来源清单能定位每份材料，并准确显示完整、部分或失败。
- 证据、分析、咨询、交接和简历各有唯一维护位置。

### 职业指导

- 每次咨询明确主题、输入、输出、时长和停止条件。
- 结论区分事实、推断和未知；没有材料时不虚构个人经历。
- 路径建议最多一主两辅，并评价机会、代价、生活约束和验证动作。
- 简历和交接的关键表述能追溯到来源编号。

### 隐私

- `career/` 不进入 Git；Git 中不出现真实文档、链接、经历、指标或内部名称。
- 提醒不包含工作原文和敏感摘要。
- 外发、共享、投递和脱敏副本均需另行确认。

### 日程

- 首周提醒显示上海时间 14:30，只在 8 月 17–21 日触达。
- 周末没有职业任务、补做、复盘或提醒。
- 晚间 21:30 停止；精力不足时缩短为 30 分钟。
