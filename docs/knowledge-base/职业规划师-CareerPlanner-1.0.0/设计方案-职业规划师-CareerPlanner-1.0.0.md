# 设计方案：职业规划师 Career Planner 1.0.0

> 状态：draft.1，待 Gate 2。

## 1. 体验原则

1. 先保全事实，再解释事实。
2. 每次咨询只解决一个明确主题，单块不超过 4 小时。
3. 用户可以直接发文件、链接或自然语言，不要求手工维护大文档。
4. 输出始终标注事实、推断、未知和下一步验证。
5. 职业发展服务生活质量，不以牺牲周末和睡眠换进度。

## 2. 信息架构

```text
生活助手
└── 职业规划师
    ├── 私有来源库：不可变原始快照 + 来源清单
    ├── 职业证据库：项目、贡献、结果、能力、缺口
    ├── 职业分析：画像、主路径、探索路径、验证计划
    ├── 咨询记录：议程、输入、结论、待办、下次问题
    └── 交付物：交接文档、主简历、案例库、求职材料
```

以上结构就是用户可直接打开查看的 iCloud 文件夹和 Markdown/原始文件，不依赖网页或数据库。Git 只保存通用规则和空白模板；带个人内容的节点均在 iCloud。

## 3. 标准咨询流程

1. **定题**：说明本次问题、时长和停止条件。
2. **盘点输入**：列出已读取来源、完整性及缺失项。
3. **结构化访谈**：每次优先询问 1–3 个高价值问题。
4. **形成判断**：区分事实、推断、未知和冲突证据。
5. **输出产物**：保存版本化文档，附来源索引。
6. **确认与回环**：让用户校正关键事实，再决定下一轮。

## 4. 原文导入体验

- 收到来源后先说明可访问范围，不先改写内容。
- 保存原始快照并生成来源编号；相同内容幂等返回已有版本。
- 新版本建立新快照和前序引用，不覆盖旧文件。
- 导入回执只显示文件名的安全代称、完整性、版本和哈希短摘要，不展示正文。
- 无权限、截断或格式不支持时，保留失败记录并告诉用户下一种安全输入方式。

## 5. 证据与分析呈现

每张证据卡包含：场景、目标、个人职责、关键动作、协作、结果、方法、来源、置信度、待确认问题。职业路径卡包含：适配点、能力缺口、机会成本、生活约束、两周验证动作和退出条件。

发散性分析单独置于“假设池”，不能直接进入简历或交接材料。

## 6. 提醒卡片

```text
职业咨询｜第 N 次｜当前阶段
今天要解决：...
已有输入：来源范围、完整性、上次结论
请你补充：1–3 项，可直接回复的格式
本次输出：文档名、包含内容、验收标准
判断边界：已确认事实 / 分析假设 / 未知
时间盒：建议时长；最低动作；最晚停止时间
结束条件：做到什么就停；未完成移到哪个工作日
```

提醒不出现原文、真实链接、公司内部名称、指标或敏感摘要。

## 7. 首周节奏

沿用 PRD 的周一至周五安排。周二、周四的 14:30 提醒同时说明晚间咨询块，不再额外晚间打扰。任何未完成事项不得移到周末。

## 8. 异常路径

- 精力不足：缩为 30 分钟，只完成来源登记或回答一个访谈问题。
- 材料尚未提供：只推进职业假设和提问框架，不伪造个人结论。
- 事实冲突：并列保留多个版本，等待用户裁决。
- 外发需求：从私有原文生成单独副本，先展示脱敏清单并取得确认。
