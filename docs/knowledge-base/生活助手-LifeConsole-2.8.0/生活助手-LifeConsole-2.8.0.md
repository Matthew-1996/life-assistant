# PRD：Life Console 2.8.0

状态：Gate 1 与 Gate 2 已由 PO 于 2026-08-31 确认；本地 TDD 实现已获授权。

## 1. 背景

现有移动端底部导航为高度 56px、左右各 12px、底部额外留白的固定胶囊。它在视觉上像浮层，但滚动内容没有真正延伸到导航下方，外层胶囊圆角与 iPhone 屏幕及底部安全区也缺少同心关系，造成底部观感割裂。

## 2. 目标

- 将 iPhone 移动端底部导航改为常驻浮动胶囊。
- 让页面内容可以出现在导航下方和两侧，建立明确的内容层与导航层。
- 以 Web 标准能力近似 iOS 26 浮动材质，不承诺原生 Liquid Glass 的折射、动态材质或系统动画。
- 正确处理 iPhone 顶部、底部安全区和 Home Indicator。
- 保持四个一级页面的导航语义、顺序和功能不变。

## 3. 已确认产品决策

1. 采用方案 2：浮动胶囊式底部导航。
2. 可以接受不完全原生的 PWA 替代方案。
3. 不做“向下滚动自动收起”，导航始终可见。
4. 不因本次视觉优化改变任何私人数据、认证、API 或自动化语义。

## 4. 范围

- iPhone / iOS PWA 与 720px 以下移动布局。
- 四个导航项继续为“工作台、记录、进展、系统”。
- 为导航项增加一致的单色线性图标；文字标签持续显示。
- 当前页使用系统蓝、轻量选中表面和字重共同表达，不只依赖颜色。
- 页面滚动层延伸到浮动导航下方；通过底部内容留量保证最后一个可操作控件仍能完整滚到导航上方。
- 处理顶部品牌栏、底部导航、Toast、编辑弹层与 safe-area 的层级关系。
- Safari 不支持或禁用背景模糊时提供不透明度更高的可读回退。

## 5. 非目标

- 不实现原生 `UITabBarController`、`UIGlassEffect` 或 SwiftUI `TabView`。
- 不实现滚动自动收起、滚动方向监听或动态折叠状态。
- 不增加 Service Worker、Cache Storage、离线页、后台同步或 Android 专项适配。
- 不改桌面端顶部导航结构。
- 不改页面路由、导航顺序、状态保持、数据库、Supabase、RLS、API、Cron 或备份。
- 不在本版本重做顶部品牌栏、卡片系统或整套图标系统。

## 6. 成功标准

1. 390×844 与当前支持的 iPhone 竖屏宽度中，导航左右留白、底部安全区和圆角形成稳定同心关系。
2. 页面内容在导航两侧和下方可见，但任何最终操作控件都能滚动到导航上方并保持可点击。
3. 四个导航项的可点击目标不小于 44×44 CSS px，图标与文字清晰、不溢出。
4. 输入键盘、Todo 编辑层、删除确认层和候选 Toast 不被导航错误覆盖。
5. `prefers-reduced-motion` 下不增加多余动画；本版本没有滚动收起动画。
6. Safari 背景模糊不可用时，导航仍保持足够对比度和可读性。
7. 既有四页切换、390px 横向溢出、PWA 安全边界与严格 CSP 回归通过。
