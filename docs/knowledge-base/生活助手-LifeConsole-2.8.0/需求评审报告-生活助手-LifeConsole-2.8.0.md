# 需求评审报告：Life Console 2.8.0

状态：Gate 1 已确认；设计 / 技术待评审。

## 1. 评审结论

需求合理且可在现有 React / Vite PWA 架构中实现，不需要新增浮层框架、后端接口或数据迁移。推荐进入设计与技术评审，暂不进入代码实现。

## 2. 角色评审

| 角色 | 结论 | 主要意见 |
|---|---|---|
| PO | 通过 | 选择浮动方案；接受 PWA 近似；不做滚动自动收起 |
| PMO | 通过 | 改变移动端视觉层级和验收口径，应作为 2.8.0 新版本管理 |
| 设计 | 通过 | 浮动层比现有半浮动胶囊更符合内容与控制分层；需固定尺寸和安全区规则 |
| 前端 | 可行 | 现有 `position: fixed`、滚动容器与 z-index 基线可复用；主要工作是全屏 viewport、安全区、图标和回归测试 |
| 后端 / 数据 | 无阻塞 | 不涉及 Supabase、API、Schema、RLS、备份或自动化 |
| QA | 可测 | 自动几何测试可覆盖多数风险；Home Indicator 和软键盘仍需真实 iPhone 验收 |

## 3. 方案对比结论

- 全宽底栏成本最低，但不符合 PO 最终选择。
- 静态浮动胶囊可以低到中等成本实现，能够满足内容透出与层级目标。
- 原生 Liquid Glass 动态折射、系统级滚动折叠不属于 Web 标准能力；本版本主动采用材质近似并排除自动折叠。

## 4. 风险与控制

| 风险 | 控制方式 |
|---|---|
| `viewport-fit=cover` 同时改变顶部安全区 | 顶栏显式加入 `safe-area-inset-top`；建立顶部和底部几何测试 |
| 内容透出后操作控件被导航盖住 | 页面底部留量 + 滚动容器 `scroll-padding-bottom` + Playwright 控件几何断言 |
| 背景复杂时文字对比度不足 | 半透明底色、细描边、阴影与无模糊回退；不追求高透明度 |
| 键盘、弹层或 Toast 与导航冲突 | 保持弹层 z-index 高于导航，调整移动 Toast 底部锚点，真实 iPhone 验收 |
| 模拟原生导致范围膨胀 | 明确不实现折射、形变、自动折叠或 JS 滚动监听 |

## 5. 成本判断

- 产品与技术方案：当前 Draft PR。
- 代码阶段：预计拆为两个不超过 4 小时的连续工作块——先完成 TDD 与结构 / 样式实现，再完成浏览器回归与真实 iPhone 验收准备。
- 真实 iPhone 产品验收、Preview、合并和 Production 分别等待 PO 当次授权。
