# Life Console 2.8.0

本版本优化 iPhone / iOS PWA 的底部一级导航：采用常驻浮动胶囊，让页面内容从导航下方和两侧透出，并以 Web 可实现的半透明、模糊、描边和阴影近似 iOS 26 的浮动导航层级。
