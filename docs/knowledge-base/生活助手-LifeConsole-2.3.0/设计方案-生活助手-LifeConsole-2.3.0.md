# 设计方案：Life Console 2.3.0

保持既有四页信息架构，不建立第二套界面。系统页把“Supabase 单一真相源”和“iCloud 只读备份”用用户语言展示，不显示项目、资源或凭据标识。

备份卡状态为：可发起、待本机处理、成功、失败。网页“立即备份”只创建 Owner-scoped 待处理任务；Mac 代理完成一致性导出、校验和原子替换后才显示成功。失败必须说明上一份备份仍有效。

所有写操作只在服务端确认后显示“已保存”。`conflict` 保留草稿并提供恢复动作；`unauthenticated` 返回登录；`unavailable` 显示未保存且不触发本地写入。
