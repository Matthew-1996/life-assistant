# PRD：Life Console 2.3.0

## 目标

1. 日记、每日状态、目标、周复盘、阶段复盘和 Apple Health 汇总只写 Supabase。
2. 网页、对话、自动回访和 CLI 共用 Owner 会话云端 Repository；失败明确未保存，不写本地第二份。
3. iCloud 只保存 Supabase 一致性导出，不允许自动反向回灌。
4. 清理既有完全重复数据，并用数据库约束阻止跨迁移批次复发。

## 数据保真

日记保存稳定键、时间与精度、隐私、来源、摘要、事实、感受、推断、人物、地点、主题、规划线索和修订信息；扩展字段进入 JSONB。每日状态补齐入睡、醒来、离床、卧床清醒。复盘保留结构化答案。

## 已授权上线范围

包含代码、数据库迁移、已确认重复清理、Vercel Production、PR squash 合并和验收。登录授权仅限本任务。职业知识库、`USER.md`、`MEMORY.md`、治理正文和非 Life Console 数据不迁移、不删除。

## 成功标准

- 固定审计预期：收口后日记 14、每日状态 15、目标 5、周复盘 1、阶段复盘 1、健康汇总 8。
- 任何计数、摘要或重复组不一致即停止删除与切源。
- Owner 可读写；未登录拒绝；非 Owner 403 无第二身份时延期。
- 最新备份可在隔离目录完整恢复，previous 在替换失败时保持有效。
