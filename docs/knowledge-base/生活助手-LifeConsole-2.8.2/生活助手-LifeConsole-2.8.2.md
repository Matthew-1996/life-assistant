# PRD：Life Console 2.8.2

状态：PO 于 2026-08-31 明确规则并要求修正。

## 1. 问题

2.8.1 将未完成 Todo 的“今日”条件定义为计划开始时间落在今日，因此会遗漏更早日期开始、但 DDL 在今天或之后的跨日 Todo。

## 2. 目标语义

- 日期判断忽略小时、分钟和秒；当地日期必须满足 `计划开始日期 ≤ 今天 ≤ DDL 日期`。
- 等价时间边界为：未完成 Todo 的 `planned_start_at < 次日 00:00` 且 `due_at >= 今日 00:00`。
- 明日 00:00 才开始的 Todo 不属于今天；今日 00:00 截止的 Todo 仍属于今天。
- 已完成 Todo 保留既有规则：`completed_at` 落在当地今日时可被状态筛选回捞。
- “全部”Tab、状态筛选、排序、甘特、写入、软删除与数据模型不变。

## 3. 成功标准

1. 更早日期开始、DDL 为今天或之后的未完成 Todo 在“今日”列表与甘特展示。
2. 今日稍后开始的未完成 Todo 继续展示。
3. DDL 早于今天或计划开始日期晚于今天的未完成 Todo 不展示。
4. 今日完成项的既有回捞语义不回归。

## 4. 非目标与门禁

- 不修改 Supabase Schema、RPC、RLS、Owner 数据或时区配置。
- 不引入定时刷新或客户端二次隐藏逻辑。
- 本地工程候选、Preview、合并与 Production 是独立门禁；当前规则确认不自动等于后续门禁通过。
