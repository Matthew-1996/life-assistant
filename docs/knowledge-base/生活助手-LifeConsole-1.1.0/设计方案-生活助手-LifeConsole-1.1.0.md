# 设计方案 - 生活助手 - Life Console - 1.1.0

## 1. 设计原则

- 同一产品：线上和本机共用页面、组件与视觉系统，不再复制一个移动看板。
- 边界优先：全局显示“私人线上只读版”和快照更新时间。
- 不伪造成功：线上不出现会产生假保存、假删除或假整理的交互。
- 隐私最小化：记录页不展示日记标题、摘要或原文，只解释如何继续通过对话/本机记录。

## 2. 页面差异

| 页面 | 本机版 | 私人线上版 |
|---|---|---|
| 今天 | 可经 Life Hub 更新锚点 | 只展示锚点当前状态 |
| 记录 | 对话、表单、整理、删除 | 隐私边界与记录入口说明 |
| 进展 | 展示七日趋势 | 展示同一只读趋势 |
| 系统 | 展示本机运行关系 | 展示快照、Sites 与 iCloud 边界 |

响应式布局沿用现有 Life Console 断点与导航；本轮不新增独立移动信息架构。
