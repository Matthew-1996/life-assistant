# 生活助手 - Life Console - 1.1.0 产品需求文档

> PO：用户
>
> PMO：Agent
>
> 项目阶段：待上线
>
> PO 决策日期：2026-08-11

## 1. 背景与目标

用户明确要求把当前本机 Life Console 部署到既有私人 Sites 项目，并停止维护两套前端。目标是获得可从移动端打开的同一 Life Console 视图，同时不把 Sites 变成新的个人数据真相源。

## 2. 范围

- 复用 `apps/life-console/` 的界面、设计系统与四页信息架构。
- 原位替换既有私人 Sites 页面；不创建第二个 Sites 项目。
- 本机版保留真实读取与写入；线上版展示按需生成的只读白名单快照。
- 线上隐藏日记输入、状态写入、整理和删除等操作，明确提示更新时间与只读边界。
- Life Dashboard 源码继续归档，不复活旧实现。

## 3. 数据与隐私边界

允许发布已获授权的当前目标、阶段、每日状态和睡眠/主观趋势投影。以下内容不得进入网页快照：日记标题、摘要与原文，Apple 健康摘要/明细，Prompt、凭据、聊天原文、机器路径和源文件指纹。站点必须保持仅所有者访问，不新增共享用户或群组。

## 4. 非目标

- 本轮不建设公网后端、云端写入、自动同步或离线编辑。
- 不删除本机代码、iCloud 真相源或可恢复 Git 历史。
- 不改变 Life Hub API、日记和每日状态的数据结构。

## 5. 验收标准

1. 既有私人 Sites URL 展示 Life Console，而不是旧 Life Dashboard。
2. 线上四页可导航，记录页没有保存、整理或删除入口。
3. 部署包不含日记内容、Apple 健康数据、Prompt、凭据或机器路径。
4. 站点访问范围读回为仅所有者，部署成功且 URL 可打开。
5. 本地 Life Console 写入能力、API 与 iCloud 数据不因线上版改变。

## 6. PO 确认

用户于 2026-08-11 直接要求将本机 Life Console 部署到指定的既有 Sites 项目并“不用重复保留”。该指令确认本版本立项、原位替换和上线动作；实现仍必须遵守既有隐私与写入审批边界。
