# 工程评审与验收 - 生活助手 - Life Console - 1.1.0

## 1. 技术评审

本版本不改变 Life Hub API 和个人台账结构。线上写入需要新的身份、冲突、审计和回滚方案，本轮明确不假设或临时拼接，因此采用只读快照是当前可验证的最小闭环。

## 2. 测试方案

- UI：Sites 模式存在全局只读提示，锚点无写控件，记录页无保存/整理/删除按钮。
- 数据：脱敏逻辑清空日记投影、替换源指纹且不修改输入对象。
- 托管：Worker 只接受读取方法、SPA 路由可回退并设置安全响应头。
- 回归：Life Console 全量测试与构建、Python 全量测试、项目校验、Git 隐私与 diff 检查。
- 上线：构建包隐私扫描，Sites owner-only 权限读回，私密部署成功并读回当前 URL。
