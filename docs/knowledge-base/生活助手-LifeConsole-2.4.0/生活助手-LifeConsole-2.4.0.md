# PRD：Life Console 2.4.0

状态：draft.1；Gate 1 已确认；待 Gate 2 方案评审。

## 1. 背景与问题

同一段生活记录从不同入口进入时，当前得到两种结果：Agent 对话会生成标题、摘要、事实、感受、人物、地点、主题、规划线索和待确认推测；Life Console 对话式记录仅用首句生成标题和事实，其余字段通常为空。现有云端 Repository 又只写入日期、标题、原文和标签，已生成的结构化字段没有进入 `journals.metadata`。

这不是展示差异，而是整理规则、字段映射和持久化契约分裂。继续分别修补会再次漂移。

## 2. 产品目标

1. 所有日记入口使用同一个版本化整理契约和同一套字段语义。
2. 用户原文先可靠保存，再异步整理；整理失败不得影响原文。
3. Agent 可用时由当前 Agent 按统一契约完成整理；无法触发 Agent 的入口使用经授权的服务端模型兜底。
4. 前端统一展示“用户原话 + 助手整理”，不再把原始段落和结构化日记当作两种产品。
5. 规则、Prompt、Schema、兼容和验收有唯一维护位置，入口文档只引用，不复制。

## 3. Gate 1 已确认决定

- J1：采用“统一日记契约 1.0”。
- J2：允许仅使用已确认个人档案补充人物关系，并标明依据；不得猜测身份。
- J3：Supabase 先保存不可变原文，结构化整理异步完成。
- J4：历史日记暂不批量重写。
- J5：允许进入 2.4.0 PRD、设计、技术与测试方案评审。
- J6：优先由 Agent 自己整理；不便触发 Agent 的网页等入口，候选兜底为 DeepSeek API。

## 4. 统一字段

### 4.1 原始事实层

- 稳定记录键与 revision
- 用户原话 `raw_text`
- 事件日期、事件时间、时间精度
- 记录来源与触发方式
- 隐私范围

### 4.2 助手整理层

- 标题
- 摘要
- 明确事实
- 明确感受
- 人物
- 地点或场景
- 生活主题
- 可能的规划线索
- 待用户确认的推测
- 标签

其中明确事实、明确感受、人物、地点、规划线索和待确认推测不是裸字符串：每一项都保存展示文字与证据依据。原文明示内容携带可在 `raw_text` 中精确匹配的证据片段；人物档案补充携带获批人物投影 revision。前端只展示友好文字，审计层保留依据。

### 4.3 过程状态层

- 契约版本、Prompt 版本
- `pending / processing / completed / failed / stale`
- 整理器类型、完成时间、失败错误码
- 整理所依据的原文 revision

## 5. 内容边界

- 原文不得被标题、摘要或模型输出覆盖。
- 明确事实和感受只能来自原文直接陈述。
- 未来愿望可进入规划线索；模型推导只能进入待确认推测。
- 缺失信息保持空数组或空值，界面显示“未记录”。
- 已确认人物资料可以补充规范称呼和关系，但必须保存 `explicit_text` 或 `confirmed_profile` 的依据类型。
- 事实、感受和规划线索必须带原文证据片段；保存前验证该片段确实存在于当前原文 revision。
- 不进行人格、关系、医疗或心理诊断。
- 标题概括核心经历，不机械截取第一句话。

## 6. 用户流程

1. 用户提交原文。
2. 云端返回“已保存、待整理”，前端立即保留原文卡片。
3. 对应处理器按统一契约生成结构化 JSON。
4. 服务端完成 Schema、事实边界和 revision 校验后写入同一日记。
5. 前端显示完整助手整理；失败时保留原文并提供安全重试。

Agent 对话可以在同一轮中完成第 3～5 步，但仍必须先取得原文保存回执。不同模型生成的措辞不要求逐字相同，字段、证据边界、空值语义和展示结构必须一致。

## 7. 历史兼容

- 已有完整结构化数据保持不变并记录其旧规则版本。
- 仅有原文的记录显示“尚未按统一规则整理”。
- 不自动把全部历史原文发送给任何模型。
- 将来需要补齐历史时，必须先生成数量、费用、数据处理方和差异预览，再单独授权。

## 8. 非目标

- 本阶段不改变每日状态、目标或复盘结构。
- 不引入第二份日记真相源。
- 不让浏览器持有模型 API Key。
- 不把 `USER.md` 或完整个人档案上传给模型。
- 不在本次方案评审阶段创建密钥、处理真实日记、迁移历史数据或部署 Production。

## 9. 成功标准

- 同一组合成案例经 Agent 与兜底链路均生成完整、可验证的统一字段。
- 任一入口都不再以首句截断代替语义整理。
- 原文保存成功而整理失败时，数据仍可读取且可重试。
- 结构化结果不能添加原文或获批人物字典以外的新事实。
- Life Console 和 Agent 使用同一渲染投影。
- Prompt 或 Schema 变化必须升级版本并经过回归，不得静默改写历史结果。
