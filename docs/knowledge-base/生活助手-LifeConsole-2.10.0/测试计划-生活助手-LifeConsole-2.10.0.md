# 测试与设计验证 · Life Console 2.10.0

## 本轮原型验收场景

0. Todo 保留完整表单、列表、状态筛选与甘特上下文，健身计划位于其下方独立一行；新版稿不显示今日锚点，实际产品数据/API 不变。
1. 默认今天、周一为首列、上/下月和跨年、回到今天；选择相邻月日期后标题与详情一致。
2. 同日超过两项显示“另有 N 项”，当日详情完整按时间排序；空日历不暗示训练未完成。
3. 新增必填校验、结束晚于开始、重叠提醒、可空地点/备注；长文本安全显示。
4. 编辑并改期后选中新日期；放弃编辑不修改原预约；删除取消与删除确认。
5. 保存失败保留输入，重试成功；冲突明确当前版本/本次输入，加载最新后才允许重提。
6. 订阅默认关闭、备注默认排除；模拟启用、停用和换链接；不产生网络请求或真实地址。
7. 模态面板键盘焦点、Esc、回焦，桌面 1280px/1440px 无水平溢出。

## 产品工程测试范围（阶段 A 结果见工程验收）

Owner/RLS 隔离、幂等重试、revision 冲突、源不可用、会话过期、时区和跨月范围、软删除；ICS UID 稳定、更新不重复、删除收敛、中文与控制字符、字段最小化、令牌哈希/撤销/更换、日志脱敏、缓存、错误响应，以及真实 Apple 客户端探针。新数据表必须纳入受控备份/恢复，迁移只在单独授权后执行。

## 证据

本轮实际运行结果维护在 PMO 中。设计稿交互验证不等于生产后端或 iCloud 同步测试。项目全量检查的既有失败或环境限制必须分别报告，不为本轮设计修改无关实现。

## 技术验收矩阵（分阶段执行）

| 编号 | 场景 | 必须结果 |
|---|---|---|
| DB-01 | 匿名、非 Owner、Owner、伪造 user_id、直接写表 | 仅 Owner 经批准 RPC 可写，不能越权读写 |
| DB-02 | 相同幂等键并发、同键不同参数、超时重试 | 单条记录；不同参数冲突；无重复审计 |
| DB-03 | 同 revision 并发更新/删除、另一端已删 | 只一方成功，不复活、不覆盖草稿 |
| UI-01 | 完整 Todo 交互、记录页 checkin、旧日记 | 不回归；只移除工作台锚点展示 |
| UI-02 | 快速切月、离开页面、登出、分页第二页故障 | 无陈旧覆盖/跨会话数据/伪空态 |
| UI-03 | 上海午夜、设备其他时区、跨月和闰日 | 业务日与预约时刻保持一致 |
| ICS-01 | 中文、emoji、逗号/分号/换行、伪 ICS 属性 | 字节正确、无注入、UID 稳定 |
| ICS-02 | 改期、改名、备注开关、删除 | revision/时间戳变化，默认无备注，不重复 |
| SEC-01 | 令牌未知/停用/更换、带 user_id 参数 | 旧链接不可读，不能选择其他 Owner |
| SEC-02 | 反代/应用错误、监控、HEAD、超限、数据库故障 | 无令牌或内容日志，不返回空 200，不共享缓存 |
| BK-01 | 新表备份、旧业务快照、隔离恢复、灾难恢复 | 预约可恢复、旧文件不覆盖，旧订阅不复活 |
| APPLE-01 | 独立合成日历增改删、自动/手动刷新、多设备 | 记录实际延迟，验证无重复和删除收敛；失败则不上订阅 |
