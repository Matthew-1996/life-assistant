# 设计方案：Life Console 2.6.0

状态：draft.1；Gate 2 待 PO 复核。

## 1. 体验设计

- 主屏幕名称：`Life Console`。
- 启动形式：独立窗口，保留 iOS 系统状态栏，不模拟原生标题栏。
- 启动路径：Production 根路径 `/`，继续由现有 Owner Auth Gate 决定显示登录或工作台。
- 安装方式：使用 iPhone 分享菜单中的“添加到主屏幕”；不在产品内增加安装横幅或弹窗。
- 离线方式：沿用 Safari / iOS 原生网络错误页，不设计品牌离线页。

## 2. 图标

- 复用现有 Life Console 蓝紫品牌方向，制作无文字、无透明圆角蒙版的正方形 PNG 图标。
- 提供 180×180 `apple-touch-icon.png` 作为 iPhone 主屏幕优先图标。
- 提供 512×512 同源母版供 Manifest 使用和后续可维护导出；本版本不扩展 Android 图标矩阵。
- 图标不包含日记、健康或用户数据，不从真实页面截图生成。

## 3. 页面表现

- 保持现有浅色主题与 `color-scheme: light`。
- iOS 状态栏使用默认浅色页面兼容样式；不使用沉浸式透明状态栏，不新增顶部安全区重排。
- 现有移动底部导航已使用 `safe-area-inset-bottom`，本版本只做回归验证，不重构导航。
- Safari 普通浏览与主屏幕独立窗口使用同一套页面，不因安装状态隐藏功能或改变数据语义。

## 4. 状态与提示

| 状态 | 表现 |
|---|---|
| 在线首次打开 | 现有加载 / 登录 / 工作台流程 |
| 从主屏幕启动 | 独立窗口，无 Safari 地址栏 |
| 离线重新启动或刷新 | Safari / iOS 原生网络错误 |
| 在线页面中途断网 | 已加载页面可能保留；后续网络读写沿用现有失败反馈 |
| 恢复网络 | 用户重新加载或重新打开应用 |

## 5. 设计验收

- 真实 iPhone 主屏幕图标清晰、名称完整、不使用字母占位图标。
- 独立窗口的状态栏、顶部品牌区和底部导航没有遮挡。
- 390px 页面仍无根级横向滚动。
- 页面没有新增“支持离线”“已缓存”或“自动安装”等不准确文案。
