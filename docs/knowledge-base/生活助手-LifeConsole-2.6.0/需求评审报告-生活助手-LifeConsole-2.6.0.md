# 需求评审报告：Life Console 2.6.0

状态：Gate 1 已由 PO 于 2026-08-29 确认。

## 1. 结论

需求成立。虽然实现范围小，但会改变安装方式、启动窗口、静态资产和验收标准，因此不走未留档的快速维护，单独建立 2.6.0。当前只完成需求、设计与技术草案；未进入实现。

## 2. 已确认方向

| 议题 | 决策 |
|---|---|
| 目标平台 | 仅 iPhone / iOS Home Screen Web App |
| 实现级别 | 仅安装配置 |
| 离线体验 | 接受 Safari / iOS 原生网络错误 |
| Service Worker | 不引入 |
| 离线数据 | 不提供 |
| Android / App Store | 非目标 |

## 3. 方案比较

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| 仅安装配置 | 最少代码、零 Service Worker 缓存、更新链路简单 | 离线是系统错误页；断网时已加载页面不会立即隐藏 | PO 已选择 |
| 受控离线页 | 离线提示更友好，可限制缓存白名单 | 需要 Service Worker、更新与缓存测试 | 本版本不做 |
| 缓存应用壳 | 弱网启动更快 | 陈旧资产和离线状态复杂，不符合在线唯一可用方向 | 拒绝 |

## 4. 风险与控制

- 图标不符合 iOS 规则：提供 PNG `apple-touch-icon` 并在 HTML 明确引用；Manifest 同时声明图标。
- 独立窗口没有生效：Manifest 使用 `display: standalone`，并保留 iOS 兼容元数据。
- 用户误解为支持离线：文档明确写明无离线能力；不使用“可离线”文案。
- 已加载页面在断网后仍可见：作为方案 2 的已知限制写入 PRD 与验收，不宣称严格实时联网门禁。
- 缓存边界被无意扩大：测试固定断言无 Service Worker 文件、注册调用或 PWA 缓存插件。
- 图标或安装配置影响严格 CSP：全部资源同源，不增加脚本策略、外部域名或内联运行时代码。

## 5. 评审结论门禁

PO 已确认 PRD 与上述限制，Gate 1 通过；设计与技术方案也已完成 Gate 2 确认，允许按 TDD 开始实现。该确认不授权 Preview、PR 合并或 Production 发布。
