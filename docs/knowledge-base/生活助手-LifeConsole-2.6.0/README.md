# Life Console 2.6.0

本版本为 iOS Home Screen Web App 轻量适配：让用户可以把 Life Console 添加到 iPhone 主屏幕，并以独立窗口打开。版本不引入 Service Worker、自定义离线页、离线数据或 Android 适配。
