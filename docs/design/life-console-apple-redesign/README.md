# Life Console 苹果式前端重构方案

这是已验收的 Web 端重构原型资料，用于在 GitHub 中延续产品能力、设计规范和后续前端实现。

## 文件结构

- `pages/overview.html`：工作台总览原型。
- `pages/capture.html`：记录输入原型。
- `pages/insights.html`：进展洞察原型。
- `pages/system.html`：系统边界原型。
- `colors_and_type.css`：原型使用的视觉 token。
- `assets/icons/dl_builtin_apple/`：原型所需图标资产。
- `../life-console-apple-ui-ue-guidelines.md`：长期 UI/UE 设计规范。

## 使用约定

- React 线上实现应以这些原型页面为结构和视觉基准。
- 允许保留现有核心功能语义，例如真实保存、刷新、冲突处理、删除确认和状态写入。
- 若线上实现与原型出现差异，优先在 PR 中说明原因；若差异影响视觉或体验，应先更新原型或补充规范。
- 原型资料只包含合成示例，不应加入真实日记、健康明细、外部账号标识或机器本地状态。

## 当前验收范围

- 工作台：左侧大 hero、右侧今日状态摘要、三张必要信息卡、今日锚点、隐私与保存链路。
- 记录：大对话输入卡、右侧简洁表单、保存反馈条；不展示“先预览”入口。
- 进展：自然周路径、阶段路线、主观评分和睡眠结构说明。
- 系统：本机服务、iCloud、自动化、备份、外部展示和移动端边界。
