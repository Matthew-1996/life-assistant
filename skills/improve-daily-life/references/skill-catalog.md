# 生活助手 Skill 目录

Skill 封装可重复的判断和工作流；日历、邮件、浏览器、表格、健康平台等连接器提供数据与动作。先建设高频、低风险、能形成闭环的能力。

## P0：第一版必须具备

| Skill | 解决的问题 | 典型触发 | 数据/工具 | 权限 |
|---|---|---|---|---|
| `build-life-profile` | 建立目标、约束、偏好、安静时段和授权边界 | “以后做我的生活助手” | 用户访谈、个人资料文件 | 写长期记忆前确认 |
| `maintain-life-goals` | 新增、排序、暂停、完成和替换生活目标 | “睡眠以后不一定还是第一目标” | 目标台账、复盘记录 | 长期保存或改排序前确认 |
| `curate-personal-memory` | 从日常对话中提炼可纠正、可删除的稳定记忆 | “记住我周三不排晚饭局” | 本地记忆文件 | 敏感项逐条确认 |
| `plan-today-realistically` | 合并日程、任务、精力与缓冲，减少过载 | “今天怎么安排” | 日历、任务、天气 | 读取可直接；改日程需确认 |
| `brief-the-day` | 只呈现今天真正重要且可行动的信息 | “给我晨间简报” | 日历、任务、天气、重要邮件 | 默认只读 |
| `review-life-weekly` | 找趋势、摩擦和下一周一个小实验 | “帮我复盘这周” | 周记录、日程、任务 | 修改系统前确认 |
| `gate-personal-actions` | 按影响、可逆性、隐私和资金风险决定是否审批 | 所有外部动作 | 工具调用元数据 | 高风险必须确认 |

## P1：明显提升生活质量

| Skill | 核心输出 | 边界 |
|---|---|---|
| `support-sleep-and-energy` | 睡眠/精力趋势、日程调整、小实验 | 不诊断、不改药；危险信号建议就医 |
| `plan-meals-and-groceries` | 现实菜单、复用食材、合并购物清单 | 过敏和疾病饮食需专业确认 |
| `organize-personal-finance` | 现金流概览、账单、储蓄目标、异常提醒 | 默认只读；不交易、不转账 |
| `maintain-relationships` | 纪念日、承诺、联系建议、消息草稿 | 不代发；不推断关系隐私 |
| `maintain-home` | 家务轮转、耗材、保养和报修计划 | 购买、预约和上门服务需确认 |
| `plan-errands-and-travel` | 营业时间核验、路线、清单、缓冲与备选 | 预订、支付、取消需确认 |

## P2：个性化后再建设

| Skill | 适用情形 |
|---|---|
| `protect-focus-and-digital-space` | 通知过载、文件/照片/订阅整理 |
| `support-learning-and-hobbies` | 有明确学习或兴趣目标，需要稳定节奏 |
| `prepare-health-appointments` | 整理症状时间线、问题清单和检查资料 |
| `coordinate-family-care` | 有照护、育儿或多人协作责任 |
| `discover-local-life` | 周末活动、餐厅、运动和社区资源推荐 |

## 当前环境可复用的能力

- 日历与忙闲：`lark-calendar`
- 任务与清单：`lark-task`
- 邮件：`lark-mail`
- 联系人：`lark-contact`
- 文档、笔记与知识库：`lark-doc`、`lark-wiki`
- 表格与跟踪器：`lark-sheets`、`spreadsheets`
- 会议与承诺提取：`lark-minutes`、`lark-vc`
- 实时公开信息：网页搜索、天气与浏览器

如果用户实际使用 Gmail、Google Calendar、Notion 等服务，再在明确同意后增加相应连接器。连接器只授予完成已选工作流所需的最小权限。

## Skill 验收问题

每个 Skill 上线前至少验证：

1. 三个正常触发请求和三个不应触发的请求；
2. 缺数据、数据冲突、时区跨日和外部服务失败；
3. 高风险动作是否在工具调用前暂停；
4. 输出是否减少用户下一步思考，而非增加管理负担；
5. 是否能解释使用了哪些事实、哪些只是推断；
6. 是否不会把秘密、第三方信息或瞬时情绪写入长期记忆。
7. 新目标加入时是否重新排序，而不是把所有目标和提醒继续叠加。
