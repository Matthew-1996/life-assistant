# 生活助手 Agent 公开来源评分表

评分不是对项目整体的安全认证，只表示它作为本项目设计依据的可信程度。社区 Skill 即使通过市场扫描，也需要独立审查其确切版本和权限。

| 来源 | 类型 | 可信级别 | 借鉴内容 | 不直接采用的部分 | 本项目处理 |

| [Agent Skills Specification](https://agentskills.io/specification) | 开放规范 | A | `SKILL.md`、触发描述、渐进加载、引用目录 | 实验性 `allowed-tools` 跨客户端支持不一 | 直接采用核心格式 |
| [Anthropic skills](https://github.com/anthropics/skills) | 官方示例库 | A | 精简 Skill、description 触发、按需资源 | 示例多为文档/工程领域 | 用其方法创建生活 Skill |

| [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) | 官方实现 | A | sessions、HITL、guardrails、tracing | 当前工作区不是 SDK 应用 | 作为未来运行层参考 |

## 关键判断

1. 官方材料对 Agent 架构、Prompt、记忆和安全的指导较成熟，但几乎没有开箱即用的“全生活”Skill。
2. 社区生活类 Skill 能提供场景清单，却常把提醒、脚本、网络访问和写权限混在一起。
3. 最稳妥的路线是本地重构工作流，只连接用户真实使用的数据源，并对每个外部动作单独授权。
4. 安装量、GitHub 星数、市场排名和自动扫描只能帮助筛选，不能替代源码、依赖、权限和运行时审查。
